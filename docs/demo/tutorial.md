# PhotoDesk · 照片台上手教程

PhotoDesk 把 Apple“照片”中的图片联系成生活、猫咪和会议片段。打开后自动归集整个可访问图库，再在后台补充本机内容识别；你可以边整理边浏览。

## 第一次打开

1. 从 [PhotoDesk 产品主页](https://app-mac-photodesk.tianli.cyou/) 获取 Mac 版 ZIP，解压后将 `PhotoDesk.app` 拖入“应用程序”。当前下载版面向 Apple Silicon Mac；系统版本要求见下载页。
2. 当前直接下载版尚未公证。如果 macOS 阻止打开，先核对下载来源，再到“系统设置 → 隐私与安全性”查看阻止记录，按系统提供的“仍要打开”入口处理。无需关闭 SIP 或全局关闭 Gatekeeper。
3. 打开应用。如果提示“无法访问照片”，在“系统设置 → 隐私与安全性 → 完全磁盘访问权限”添加并启用 PhotoDesk，退出后重新打开。
4. 默认使用 Apple“照片”最近打开的图库。要整理另一份图库，点右上角“选择图库”，选择对应 `.photoslibrary`。首页出现片段后即可浏览；后台识别进度会继续更新。

## 浏览和选择

在左侧切换“我的时间线”、猫时间线或“会议与工作”。分类是供你核对的联系线索；没有名字的猫不会被擅自归为某个个体。分类不合适时，可在设置中调整已命名的猫、事件间隔、距离和会议资料关联范围。

首页卡片代表整个片段。**单击先选中**，不会直接进入详情；底栏同时显示片段数和可操作照片数。按住 ⌘ 单击增减选择，按住 ⇧ 连续选择。共享照片可以查看，但不计入可删除数量。核对多选期间，后台归类不会改变已选片段的成员。

选中片段后按 **空格**预览封面。需要逐张选择时，点独立的“查看片段”按钮进入详情。在照片网格里，单击选择图片，空格、双击或“放大查看”进入同一预览；空格或 Esc 关闭，方向键用于浏览。预览关闭后仍保留选择。搜索框输入文字时使用正常文本编辑操作。

## 核对重复建议

点“重复核对”，查看同组照片、保留理由和当前勾选。预选要求文件字节一致，而且保留副本覆盖另一份的独有元数据；相似画面不等于完全重复。收藏、隐藏、独立编辑、Live Photo 和视频不会自动预选删除。

你可以取消预选或调整选择。后台刷新不会重置正在核对的勾选。只有你最终确认的精确照片才会进入删除流程；系统可能再次要求确认。删除会影响原照片及其 iCloud 同步副本，请核清文件名与选择数量后再继续。两段录像只展示建议，没有执行删除。

## 设置与故障恢复

- 按 **⌘,** 或点左下角“设置…”打开设置，修改后自动保存。可暂停整理、调整范围和识别强度；退出后再次打开会继续使用本地已完成的识别缓存。
- 自定义快捷键默认全部为空；在“设置 → 快捷键”中可录制、清除、选择作用范围并查看冲突提示。
- 已给“照片”权限却仍读不到图库：读取图库所需的“完全磁盘访问权限”与删除所需的“照片”权限是两项不同设置。启用完全磁盘访问后退出重开，并确认所选图库仍存在。
- 个别识别失败：先检查原片在本机是否可用，再用设置中的“重试失败的识别”。未下载原片不会做 OCR，也不会因为没有 OCR 文字被当作垃圾。
- Apple 相册或标题写回位于“整理 → 高级整理”，需明确确认，可能触发系统自动化授权。普通自动归类只保存在 PhotoDesk。
- 遇到持续错误，记录版本、macOS 版本、操作步骤与错误文字。反馈前遮住截图中的私人照片、人物、地点及文件名；不要直接发送整个图库或识别缓存。误删时先到 Apple“照片”的“最近删除”查看恢复入口，是否仍可恢复以系统显示为准。

## 照片与识别数据在哪里

照片分析和 OCR 在本机执行，不调用外部模型、不上传照片。运行数据保存在 `~/Library/Application Support/PhotoDesk/`；Apple“照片”自身的 iCloud 同步仍由你的系统设置决定。共享相册、共享图库及未保存的共享消息照片保持只读。
