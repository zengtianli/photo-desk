PhotoDesk 安装与使用

1. 将 PhotoDesk.app 拖到 Finder 的“应用程序”，再从“应用程序”打开。
2. 当前下载适用于 Apple Silicon（M 系列芯片），要求 macOS 15 或更新版本。
3. 这是本地签名、尚未公证的直接分发版本。若 macOS 阻止打开，请先核对下载来源，
   再到“系统设置 → 隐私与安全性”查看本次阻止记录，按系统提供的“仍要打开”操作。
   系统如果要求认证，使用你这台 Mac 的登录密码或 Touch ID。
   不需要 Apple ID 密码，也不要关闭 SIP 或全局关闭 Gatekeeper。
4. 第一次读取图库若显示无权访问，在“隐私与安全性 → 完全磁盘访问权限”添加
   并启用 PhotoDesk，然后退出并重新打开。这里的权限与“照片”访问权限不同。
5. 默认读取 Apple“照片”最近打开的图库，也可以在 PhotoDesk 中选择 .photoslibrary。
   本机整理会自动开始。先按日期、已有相册和人物归集，再逐批识别可访问的内容。
   识别进度代表实际已处理项目；缺少原片时不会自动从 iCloud 下载。

浏览：单击选择，⌘单击增减，⇧单击连续选择。空格预览，Esc 关闭，方向键翻图。
首页卡片代表整个时间片段；双击或“查看片段”才进入逐张浏览。⌘, 打开设置。
照片内容及 OCR 留在 Mac。本地时间线不会自动改写 Apple 相册。

重复核对：建议只是预选。核对保留副本、文件和元数据后再决定是否删除。
删除前需要明确选择与确认，还可能出现系统确认；共享内容只读。
删除会影响原照片，并随 iCloud 同步到其他设备。恢复请使用 Apple“照片”的
“最近删除”；恢复期限由系统显示，不要把它代替备份。
